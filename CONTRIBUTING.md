# Contributing Guide

## How to Contribute
1. Fork the repository.  
2. Create a feature branch: `git checkout -b feature/my-feature`  
3. Commit changes: `git commit -m 'Add my feature'`  
4. Push to the branch: `git push origin feature/my-feature`  
5. Open a Pull Request and link relevant issues.  

## Coding Standards
- Use consistent linting rules (e.g., PEP8 for Python, ESLint for JS).  
- Include tests for new features.  
- Document new functions and modules.

## Reporting Issues
- Search existing issues first.  
- Provide a clear, reproducible description.  

## Getting Help
- Join discussions on GitHub Discussions.  
- Ask questions constructively and review community guidelines.
